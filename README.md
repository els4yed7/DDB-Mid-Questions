# Mid Questions MCQs — Quiz

Static site (no build step). 85 questions, instant feedback, explanations, review screen.

## Deploy on Vercel

Option A — CLI
    cd mid-questions-quiz
    npx vercel --prod

Option B — GitHub
1. Push this folder to a GitHub repo.
2. vercel.com/new -> import the repo.
3. Framework Preset: Other. Leave Build Command and Output Directory empty. Deploy.

## Edit the questions
The questions live inside index.html as the DATA object (top of the <script> tag).
